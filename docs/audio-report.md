# Audio report

Generated by `node scripts/process-audio.mjs`. Nobody has listened to these
files: every number below is measured from the encoded MP3, so a person can
audit by ear later and know where to start.

- Files: 288, 8.03 MB in `public/assets/local/sounds/`
- Format: 44.1 kHz MP3 (LAME, constant bit rate): 128 kbps mono for one-shots, 160 kbps stereo for tails and beds, 96 kbps mono for positional loops
- Loops are periodic with 0.3 s of the neighbouring cycle on each side; the engine loops between the points in `src/audio/sound-meta.json`, so decoder padding cannot open a gap. "Seam step" is the jump across the loop point in units of the signal's ordinary sample-to-sample step (about 1 is seamless, 5 or more would click)
